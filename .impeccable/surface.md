# Deck workspace
Mode: Operate. Issues #16–#18 extend the visual identity established by #9 into a shared header, dedicated deck editor and deck library.

THESIS: Give deck building its own workspace, with a clear route into discovery and back, while keeping secondary tools within their relevant surface.
OWN-WORLD: Warm paper, forest-green ink, Newsreader headings, Public Sans controls, fine rules and authored diamond/card SVGs. Dark appearance supports evening use; device appearance is the default.
FIRST VIEWPORT: Shared horizontal Explore cards / My decks / Settings header, compact browser-local save status and Help. The editor leads with name, format, counts, labeled identity and Find cards to add, followed by deck management, Cards / Statistics / Checks and grouping/filtering. My decks stays selected in the editor. The library leads with New deck / Import deck and responsive deck cards. Discovery leads with the named destination deck/Main deck zone and Open full deck, search, collapsed Filters/function browser and starting searches, beside the secondary deck panel. On phones navigation wraps onto a second horizontal header row; editor controls use two columns and card rows stack mana/zone controls; library cards form one column. Discovery retains its fixed deck shortcut.
SIGNATURE: Complete card portraits, fine ruled deck zones and labeled mana identity carry the collector’s index across library and editor. In discovery, expand a function, select a tag, then collapse the browser; the selected tag remains a removable chip beside the results.
BEHAVIOR: Native details disclosure; open state survives rerenders. Appearance and complete workspace backups live in Settings. Cards groups by type or first ordered personal role, filters every assigned role/type, orders by name/mana/quantity and edits copies/zones; Statistics shows the curve; Checks preserves partial-validation notices. Hover/focus previews on desktop and keyboard/touch details preserve complete cards. Roles still require Save zone and roles (#25 remains open scope). Library/editor management includes rename/format, independent duplicate, text import, text/complete deck JSON export and named deletion confirmation with Keep deck focused first. Creation can designate a commander or defer it; designation is not eligibility validation. Find cards to add retains explorer state and names the destination; Open full deck returns. Optional/resizable explorer tracker remains #19.
MOTION: Existing card hover lift and search loading feedback; reduced-motion override retained.
FINISH: Code-led extension of the retained world; no new palette, type system or generated assets. Reviewed editor desktop/mobile light/dark, library desktop/mobile dark and details mobile dark screenshots against implementation. Windows desktop/390px light/dark browser checks covered lookup/import, roles, moves/copies, duplication, rename, deletion cancellation, reload and keyboard use; automated core/workspace verification is separate evidence. Impeccable context and visual-detector engine unavailable; no automated visual-detector result, generated comp or design approval is claimed. macOS/Safari untested.
