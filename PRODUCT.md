# Arcana
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the request for an autonomous MVP: native browser modules, CSS, Node.js 22+ standard-library server. No install dependencies. Runs on Mac and Windows.
## Users and purpose
Magic players building decks and exploring cards who currently move between Scryfall, Tagger, and Archidekt. Bring discovery, deck editing, statistics, and format feedback into one workspace.
## Capabilities and constraints
Local browser storage, Scryfall live API, guided combinable function tags and Oracle filters, full advanced syntax, deck creation, import/export, mana curve and category counts. No authentication or cloud synchronization in this MVP. Tag suggestions are curated rather than a complete Tagger taxonomy. Format checks are a useful subset, not a tournament certification. User requested deferring unspecified decisions until later feedback.
## Open decisions
Accounts and cross-device storage, full taxonomy access, partner commanders, sideboards, collection tracking, and native desktop packaging.
