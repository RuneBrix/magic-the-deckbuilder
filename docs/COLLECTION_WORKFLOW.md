# Collection workflow

Implemented in [PR #86](https://github.com/RuneBrix/magic-the-deckbuilder/pull/86).

Large imports batch up to 75 unique unconstrained names per request and reuse duplicate printing lookups. Rows already constrained by set/language skip the redundant initial name lookup. Review displays lookup/row progress. Successful batches and alternate searches remain cached in the open import window after failures: keep it open and use Resume review after a rate-limit cooldown. Collection changes apply only after the complete review. Closing/reloading discards this temporary progress.

All server endpoints share one upstream queue with at least 600 ms between requests after completion, coalesced pending lookups and a bounded five-minute response cache. A 429 stops queued/new network calls and returns a cooldown of at least 60 seconds, respecting longer Retry-After values. Review disables retries during that interval and requires an explicit resume; there is no automatic retry storm. Other apps or server processes using the same IP are outside this queue. Server changes require restarting the existing localhost server before retrying.

Collection fills the page with compact View, Group by, Sort by and Filter cards controls. Visual cards retain fixed portrait sizes; horizontal/vertical text views use compact rows. Group by type, color or set, or leave ungrouped. Sort by date added, updated at, name, quantity, color, regular EUR price or set/printing. Initial settings use visual cards, no grouping and newest-added first; the last-used controls and filter are remembered in this browser. Older lots without dates use their stored order as a fallback. New lots record added/updated dates, and edits preserve added dates.

Add owned card searches after one character. The dropdown is anchored to the input and contains only matching card results. Typed characters are literal and match the beginning of card names. Arrow keys and Enter select results. Selecting opens a staged editor with artwork, paginated printing choices, finish, condition and absolute quantity. The current stored quantity is shown for the selected printing/finish/condition. Plus, minus and direct entry change the draft. Update collection applies it; Cancel, Escape and X discard it. Zero removes that lot.

Import card list accepts quantity/name text and Archidekt CSV, pasted or selected as a `.csv` file. CSV supports Quantity/Qty, Name/Card Name, Finish/Foil, Condition, Language/Lang and Edition Name/Code or Set Name/Code. Columns may be omitted except Quantity and Name. Purchase prices, tags, source dates and other columns are ignored. Normal maps to regular; common foil booleans, NM/LP/MP/HP/Damaged and language names/codes are normalized. Unknown values or malformed CSV block the whole import. Quoted commas, escaped quotes and duplicate rows are supported.

Review shows every resolved printing, language, finish and condition before adding copies. Explicit set/language constraints must resolve one supported printing; unresolved or ambiguous variants require refinement or manual addition. Missing set/language uses the default resolved printing, shown for confirmation. No numeric edition identifier is assumed to mean a collector number. Matching printing/finish/condition rows combine; different languages retain different printing IDs. Text imports default to regular finish and unrecorded condition; zone headings do not create collection zones. Applying the review adds quantities rather than replacing the collection.

Complete workspace v2 files retain the collection and deck budget settings. Each deck independently allocates owned copies; Main, Command and Sideboard count toward planning, while Maybeboard remains excluded.

Arcana stores Normal finish as `regular` and checks it against Scryfall's `nonfoil` value. If an unconstrained name resolves to an incompatible finish, import searches alternate printings and filters their actual finish support. Full double-faced names can fall back to a front-face search while still validating the complete returned name. The supplied Aang/Aang/Abandoned Air Temple example has been reviewed successfully through the live localhost proxy without changing browser inventory. Re-run explicitly with `ARCANA_LIVE_CSV=1` and the `live localhost review` test-name filter; the ordinary suite skips this network-dependent check.
