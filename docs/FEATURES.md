# Feature status

Collection ownership, TXT/CSV uploads and EUR deck planning are implemented in merged PR #86. [Collection workflow](COLLECTION_WORKFLOW.md) owns the current behavior and limits; GitHub records review evidence and remaining follow-ups.

This inventory describes what the app does today. GitHub Issues track future work; linked pull requests and commits record its implementation. Update this file when behavior changes.

**Implemented** means present in the checked-out app, not necessarily merged, developer-accepted or exhaustively verified. GitHub holds live issue/PR review state. **Partial** names a known ceiling. **Planned** means not implemented and not a delivery promise.

## Validation baseline

The [Statistics tool board](DECK_WORKSPACE.md#viewing-and-scrolling-follow-ups-53--57--61) has desktop and narrow Chromium coverage in light and dark modes ([#57](https://github.com/RuneBrix/magic-the-deckbuilder/issues/57)). Optional empty zones ([#53](https://github.com/RuneBrix/magic-the-deckbuilder/issues/53)) and sticky navigation ([#61](https://github.com/RuneBrix/magic-the-deckbuilder/issues/61)) also have Chromium desktop/phone light/dark acceptance at localhost:3000, including all four deck layouts, tracker transitions, overlays and desktop drag destinations. The navigation batch fixes delayed-scroll menu dismissal and covered final phone tracker controls. See the linked workspace contract for dates, viewport sizes and platform limits.

Historical baseline only: the initial MVP passed eight automated checks (`npm test`) and live browser checks for search, card addition, reload persistence, atomic imports, and desktop/mobile layouts. These are the baseline, not a claim of full feature coverage. New fixes need validation appropriate to their behavior.

See [the roadmap](ROADMAP.md) for proposed work and [the development workflow](DEVELOPMENT.md) for how status changes are recorded.

## Mana/color symbols (#56)

Implemented: a locally bundled Mana font replaces lettered W/U/B/R/G indicators across identity, statistics, costs and guided filters. Colorless uses its diamond; generic and compound costs retain distinct literal notation. Accessible names, asset provenance and current browser verification limits are recorded in [MANA_SYMBOLS.md](MANA_SYMBOLS.md).
