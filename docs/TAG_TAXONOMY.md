# Function-tag discovery

Implemented for [D01 / #1](https://github.com/RuneBrix/magic-the-deckbuilder/issues/1).

## Source and access

The bundled catalog comes from Scryfall's public Oracle Tags bulk export. The 2026-11-11 export supplied 4,605 Oracle tags, including canonical slugs, aliases, parent and child IDs, and direct taggings. For each tag the generator counts distinct `taggings[].oracle_id` values and ships the count plus every direct membership, indexed by Oracle identity into the sorted tag list. A valid empty list yields zero. A missing or invalid membership list aborts the refresh and leaves the previous snapshot intact. [Oracle Tags export](https://api.scryfall.com/bulk-data/oracle_tags) · [Bulk Data](https://scryfall.com/docs/api/bulk-data) · [Tags](https://scryfall.com/docs/api/tags)

The catalog is a dated, community-maintained snapshot. Counts cover direct Oracle memberships across the export. Live `otag:` search can match cards tagged with related functions. For example, `ramp` has 582 directly tagged cards in the 2026-11-11 snapshot, while `game:paper otag:ramp` returned 2,291 matches on 2026-11-23. Arcana uses Scryfall's reported search total because the snapshot's recorded relationships do not guarantee a match in the live index or under a particular filter. [Scryfall card search](https://scryfall.com/docs/api/cards/search)

## Update strategy

Run `npm run update:tags` from the repository root with Node 22+ and network access. It resolves the current official export URL, downloads the gzipped JSONL, validates names and references, and atomically replaces `public/tag-catalog.js` only after conversion succeeds. Review the generated diff and date, run `npm test`, and commit the snapshot alongside any necessary starting-point changes. Refresh during release preparation or when a user reports missing or renamed tags; no download occurs during app startup. The last shipped snapshot remains usable if an update fails.

The generated file contains source URL, upstream timestamp and stable upstream UUIDs (`uuid`). Its `id` is the current query slug, used only for this snapshot's navigation and session filters; slugs are not permanent upstream identifiers. Use UUIDs to compare renamed tags across updates. Keep aliases and relationships sourced from the export. `TAGS` in `public/core.js` contains Arcana's curated starting labels and descriptions; these are additional search terms, not purported upstream aliases. Starting points must reference a canonical tag in the snapshot, as enforced by tests. Replace obsolete starting points when updating rather than inventing relationships.

## User behavior and limits

- Find a function searches names, upstream aliases and curated starting labels and descriptions. Spaces and hyphens are interchangeable. Exact matches appear first. The count reflects available matches after excluding selected functions. Blank search shows ten starters and fills a slot as soon as its candidate is selected. Each search page holds up to ten matches in a reserved area. Previous, Next, the editable page number and Jump to page navigate the same matches. A new lookup returns to page one. Tiles label counts as directly tagged. The dated counts are available offline. Typing and paging make no requests.
- Related opens a dialog with broader function links, a narrower function selector, Back and Forward, the dated direct count, aliases and the original Tagger page. The dialog shows Scryfall's total for `game:paper otag:<canonical-tag>` and up to eight examples from its first page, using the normal popularity sort. Add filter or Remove filter updates the existing selection and all/any query. Search cards uses the resulting full query, including any other filters and any paper restriction entered there. Navigation leaves the query alone. Closing returns focus to the Related trigger when it is still available, or to Find a function after the trigger is removed.
- The dialog waits briefly before requesting one search page per visit and discards responses for closed or superseded views. The existing proxy paces requests and caches successful responses for five minutes. Missing totals show as unavailable. Failed example requests can be retried without changing the query. Catalog navigation and direct counts remain available offline.
- When the catalog has no match, Add as an unlisted function accepts up to 80 letters, numbers, spaces or single hyphens. It adds a lowercase, hyphenated `otag:` filter. Scryfall may reject an unlisted tag or return no cards. Matching aliases use their canonical slugs. Related shows the snapshot date alongside the direct count.
- Matching all (AND) sends space-separated `otag:` terms; Matching any (OR) joins them with `OR`. The primary editable Scryfall query shows the effective expression; supported clauses project into guided controls as described in [UNIFIED_SEARCH.md](UNIFIED_SEARCH.md). Other filters are retained.

## Automatic primary functions (#46)

The same official Oracle Tags snapshot retains all 240,183 distinct direct memberships for 36,453 Oracle identities, indexed into the canonical tag list. These sourced memberships are separate from the entry's private ordered `tags`. `functionMemberships()` exposes the complete direct list, and `suggestedFunctions()` ranks broad families from the snapshot's recorded parent relationships ([#210](https://github.com/RuneBrix/magic-the-deckbuilder/issues/210)).

Ordinary single-faced lands default to **Land** from their type line, including artifact lands, without needing a tag membership or Oracle identity (#163). This applies to normal-layout cards and legacy records with no layout/faces or double-face separator. Double-faced cards, including land-front/land-back cards, use tag-based defaults instead of being forced to Land.

Each direct membership contributes one vote to each reachable root, even if several parent chains lead there. A tag without parents represents its own family. If a cycle has no reachable root, use the directly recorded tag. Color-effect parents describe a color association, so the walk stops at their child (for example, Counterspells stays a function). Descriptive families such as naming, set cycles and ability timing rank after effect families and remain available when they are the only evidence.

Established deck labels add one vote when their family is present. Higher total support wins, then the longest of the shortest paths from a direct tag to the family, then the canonical slug alphabetically. Familiar labels include Ramp for `cost-reducer`, Protection for `pillowfort`, Combat control for `combat-manipulation`, and Untap for `untapper`. Other labels use the family slug as words. A sweeper can now join Removal through its recorded parent, while a directly tagged `evasion` card can initialize Evasion. These choices apply to the initial deck label independently of live `otag:` search.

The ten Karona regression cards retain their reviewed defaults, including Curse of Bounty in Untap, Eye of Nidhogg in Combat control, and Inquisitive Glimmer in Ramp. Their printing and Oracle identities were verified against the Scryfall card API on 16 November 2026.

Every ordinary deck-add path uses the card's Oracle identity, independently of search filters. This includes Search cards, Quick add, details, deck-card copies, text import, commander creation and the example deck. The highest-ranked function initializes a new entry when there is no explicit or inherited assignment. Beast Within (`7735eeba-693b-47e2-bd51-414379cf1016`) receives **Removal** from its recorded memberships.

Explicit primary input, inherited functions and existing assignments take precedence. Adding a copy to an existing entry with no stored label keeps its current state. Assign card to function offers **Use suggested function: …** when a different default is available, including for older unassigned entries. Selecting that action applies it. **Unassigned** deliberately clears the primary and stores a blank first tag while retaining secondary personal labels. JSON restores retain saved entries exactly. Grouping, filtering, statistics and draw probability use the first private label, and JSON retains the complete ordered labels.

For an already imported deck, **Deck actions → Assign missing functions…** reviews suggestions for entries with no stored functions across all zones. Nonempty function lists, including the explicit blank-primary marker, are excluded. Cards without a known default are left alone. Cancel applies nothing; confirmation rejects changed suggestions and persists a staged deck before updating live cards. A failed save keeps old saved/live data and permits retry without changing quantities, printings or collection inventory. This avoids reimporting copies merely to fill missing labels.

Classification makes no network requests and works offline after the local app loads. The snapshot covers identities with recorded taggings. Cards without an Oracle identity or without a bundled membership, including newly released cards, can remain Unassigned or receive a manual function. The Add card dialog shows the suggested default when available and links the source. The [snapshot update strategy](#update-strategy) governs freshness. Refreshes update future suggestions and preserve saved assignments. The indexed membership data is bundled with the app and stays outside deck/workspace exports.
