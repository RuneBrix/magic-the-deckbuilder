# Bundled fonts

These unmodified variable TrueType fonts are self-hosted; the interface makes no Google Fonts request.

- Newsreader, Production Type: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/newsreader), `Newsreader[opsz,wght].ttf`. License: `Newsreader-OFL.txt`.
- Public Sans, USWDS and contributors: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/publicsans), `PublicSans[wght].ttf`. License: `PublicSans-OFL.txt`.

Downloaded 2026-10-26. Both use the SIL Open Font License; keep the accompanying license files when distributing the app.

License: `Mana-OFL.txt`; upstream notice: `Mana-README.md`. Symbol images copyright Wizards of the Coast. No external font request is made.
